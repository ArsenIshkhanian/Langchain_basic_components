# 🚀 Groq + Groq LangChain Demo

Welcome to my **LangChain + Groq** project!  
This repository demonstrates how to set up **basic LangChain components** — prompt templates, chat models, messages, parsers, and chains — using Groq with LangChain.  

---

## 🌟 Features

- ✅ Install and configure **LangChain** and **LangChain-Groq**  
- ✅ Set your **API key** for Groq  
- ✅ Create **Human, AI, and System messages**  
- ✅ Use **output parsers** to process model responses  
- ✅ Build **PromptTemplate** and **ChatPromptTemplate**  
- ✅ Use **MessagesPlaceholder** for dynamic multi-turn chats  
- ✅ Chain prompt → model → parser for clean workflow  
- 🧰 Demonstrates **basic LangChain components** for learning and experimentation
